## Integrated Laravel application

[`temp-laravel/`](temp-laravel/) contains the integrated application where the modules are brought together. Use this folder when running the complete project locally.

**Important:** The three module folders above are separated for easy review. The integrated application is kept separately in `temp-laravel/`; it is not another module submission folder.
